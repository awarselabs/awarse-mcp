### Description
SeatPrune is an open MCP server and CLI designed for GitHub organization administrators and FinOps teams. It enables AI assistants (Claude Desktop, Cursor) to:
- Audit organization member activity (commits, PR reviews, logins) across trailing 30/60/90 days.
- Calculate exact monthly/annual license spend waste on dormant accounts.
- Dispatch Slack webhook notifications and run dry-run-protected seat reclaims.
- Run 100% locally via `uvx` / standard input-output (`stdio`) to ensure GitHub admin credentials remain local.
